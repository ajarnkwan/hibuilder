คำใหม่ที่อาจเจอตลอดคอร์ส — เปิดมาดูเมื่อต้องการ ไม่จำเป็นต้องจำหมด

HTML / Code

5 คำ
HTML
เอช-ที-เอ็ม-แอล · HyperText Markup Language
ภาษาที่ใช้บอกว่า "เว็บมีอะไร" — เป็น "โครงกระดูก" ของหน้าเว็บ บอกว่ามีหัวข้อ ย่อหน้า รูป ปุ่ม อะไรบ้าง อยู่ตรงไหน
เปรียบเทียบ เหมือน "เมนูในร้านอาหาร" — บอกว่าร้านมีอะไร ขาย ไม่ได้ตกแต่ง
เจอใน: Step 1.6, 1.7
CSS
ซี-เอส-เอส · Cascading Style Sheets
ภาษาที่ใช้ "แต่งเว็บให้สวย" — กำหนดสี ฟอนต์ ระยะห่าง ขนาด เลย์เอาต์
เปรียบเทียบ เหมือน "การตกแต่งร้าน" — สี ป้าย พื้น โต๊ะ
เจอใน: Step 1.6
JS (JavaScript)
เจ-เอส · ภาษาโปรแกรม
ภาษาที่ทำให้เว็บ "เคลื่อนไหวและตอบโต้" — กดปุ่มแล้วเกิดอะไรขึ้น คำนวณตัวเลข บันทึกข้อมูล
เปรียบเทียบ เหมือน "การสั่งอาหาร" — ลูกค้ากด → แม่ครัวทำตาม
เจอใน: Step 1.6
Tag
แท็ก · ป้ายชื่อใน HTML
ของในวงเล็บมุม < > ที่บอกว่าส่วนนี้คืออะไร — เช่น <h1> = หัวข้อใหญ่, <p> = ย่อหน้า — Tag เปิดต้องปิด เป็นคู่
ตัวอย่าง <h1>สวัสดี</h1> — เปิด h1, ปิด /h1
เจอใน: Step 1.6, 1.7
index.html
ชื่อไฟล์ HTML "หน้าหลัก"
ชื่อไฟล์ที่ เซิร์ฟเวอร์/GitHub Pages เปิดเป็นค่าเริ่มต้น เมื่อมีคนเข้า URL — เหมือน "หน้าแรก" ของเว็บ ถ้าตั้งชื่อไฟล์อย่างอื่น URL ต้องเรียกชื่อนั้นต่อท้าย
ตัวอย่าง mybuilder.github.io → เปิดไฟล์ index.html อัตโนมัติ
เจอใน: Step 1.7
📦

GitHub

5 คำ
Repo (Repository)
เร-โป · "โฟลเดอร์โปรเจกต์"
"โฟลเดอร์โปรเจกต์" บน GitHub — เก็บไฟล์ทุกไฟล์ของเว็บเดียวไว้ด้วยกัน 1 เว็บ = 1 repo
ตัวอย่าง repo ชื่อ "mybuilder.github.io" เก็บ index.html, README.md ไว้
เจอใน: Step 1.7
Commit
คอมมิต · "บันทึกประวัติ"
บันทึก/save การเปลี่ยนแปลงเข้า repo — มี history ดูย้อนได้ เปลี่ยนใจเปลี่ยนกลับได้ ไม่เหมือน Save ทั่วไป
ตัวอย่าง commit ครั้งที่ 1: "เพิ่มไฟล์ index.html"
commit ครั้งที่ 2: "แก้สีหัวข้อเป็นน้ำเงิน"
เจอใน: Step 1.7
Deploy
ดี-พลอย · "ปล่อยขึ้นเว็บ"
ปล่อยเว็บออกสู่อินเทอร์เน็ต ให้คนทั่วไปเข้าถึงได้ — บน GitHub Pages เกิดอัตโนมัติหลัง commit ใช้เวลา 1-2 นาที
ตัวอย่าง เพิ่ง commit เสร็จ → รอ 1 นาที → เว็บ live ที่ mybuilder.github.io
เจอใน: Step 1.7
GitHub Pages
บริการของ GitHub
บริการ โฮสต์เว็บฟรี ของ GitHub — ใส่ HTML/CSS/JS ลง repo → เปิดเป็นเว็บได้ทันที ใช้ตลอดคอร์ส Hi, Builder
ข้อจำกัด เก็บได้แค่ไฟล์ static (HTML/CSS/JS/รูป) — ทำ database/backend ไม่ได้
เจอใน: Step 1.4, 1.7
README
อ่านมี · "อ่านก่อน"
ไฟล์ คำอธิบายของ repo — เป็นไฟล์แรกที่คนอื่นเห็นเมื่อเข้ามา ปกติเขียนด้วย Markdown (.md)
ตัวอย่าง # เว็บของฉัน
เว็บ checklist ของขายของซื้อ สร้างจากคอร์ส Hi, Builder
เจอใน: Step 1.7
🌐

Web

3 คำ
URL
ยู-อาร์-แอล · ที่อยู่ของเว็บ
"ที่อยู่"ของหน้าเว็บบนอินเทอร์เน็ต — เหมือนที่อยู่ของบ้าน พิมพ์ใน browser แล้วไปหน้านั้นได้
ตัวอย่าง https://mybuilder.github.io
เจอใน: ทุก Step
Hosting
โฮสติ้ง · "ที่ตั้งของเว็บ"
บริการ เก็บไฟล์เว็บไว้บนเซิร์ฟเวอร์ ที่เปิด 24 ชั่วโมง คนเข้าได้จากที่ไหนก็ได้ — ปกติเสียเงิน แต่ GitHub Pages ฟรี
เปรียบเทียบ เหมือนเช่าที่เปิดร้าน — ที่ถูก ที่ราคาดี ที่ฟรี
เจอใน: Step 1.2, 1.4
Browser
เบราว์เซอร์ · "ตัวเปิดเว็บ"
โปรแกรมที่ใช้ เปิดเว็บ เช่น Chrome, Safari, Edge, Firefox — เป็นตัวกลางที่อ่าน HTML/CSS/JS แล้วแสดงผลให้ผู้ใช้
ที่พบบ่อย Chrome (ทั่วไป), Safari (iPhone/Mac), Edge (Windows)
เจอใน: Step 1.2, 1.4, 1.7
💾

Storage

2 คำ
localStorage
โลคอลสตอเรจ · "ที่เก็บในเบราว์เซอร์"
ช่องเก็บข้อมูลใน เบราว์เซอร์ของผู้ใช้ — ของไม่หายเมื่อปิดหน้า แต่หายถ้า clear cache หรือเปลี่ยนเครื่อง
ใช้กับอะไร เก็บ Asset Map (Step 1.5), เก็บ checklist ของผู้ใช้ — เปิดมาดูใหม่ได้
เจอใน: Step 1.2, 1.5, 1.7
JSON
เจ-สัน · รูปแบบเก็บข้อมูล
รูปแบบไฟล์ เก็บข้อมูลแบบมีโครง — มนุษย์อ่านได้ คอมพิวเตอร์เข้าใจ ใช้ส่งข้อมูลระหว่างเว็บกับเซิร์ฟเวอร์
ตัวอย่าง { "name": "ป้านิด", "skill": ["ส้มตำ", "คุยลูกค้า"] }
เจอใน: Step 1.5 (download Asset Map)

Concept

3 คำ
Prompt
พรอมป์ต · "คำสั่งให้ AI"
ข้อความที่พวกเรา พิมพ์/พูดให้ AI — เป็น "คำสั่ง + คำถาม + บริบท" ที่ AI ใช้ตอบ คุณภาพ prompt ดี = คำตอบดี
Prompt ห่วย "ช่วยทำเว็บให้หน่อย"

Prompt ดี "ช่วยทำเว็บ HTML 1 ไฟล์ — checklist 5 ข้อ ติ๊กได้ ใช้บนมือถือ"
เจอใน: Step 1.3, 1.7 — เรียนลึกในบทเรียน 2
Asset
แอสเสท · "ทุนของ Builder"
"ทุน/สินทรัพย์" ในความหมายของ Builder — สิ่งที่คุณมีอยู่แล้ว ที่จะใช้สร้างของได้ ทั้งความรู้ ทักษะ Network และประสบการณ์ — ไม่จำเป็นต้องเป็นเงินหรือของจับต้องได้
ตัวอย่าง ป้านิด: สูตรส้มตำ 12 แบบ + ลูกค้าประจำ 50 คน + ประสบการณ์ขาย 8 ปี
เจอใน: Step 1.5 (key activity)
Portfolio
พอร์ตโฟลิโอ · "แฟ้มผลงาน"
การรวบรวมผลงานเพื่อโชว์ — ปกติใช้สมัครงาน รับงาน หาคนซื้อบริการ ใน Hi, Builder จบคอร์สจะมีใบ Cert + Portfolio รวมกัน
Portfolio ของ Builder ใน Hi, Builder เว็บที่สร้าง + URL + screenshot + เล่าว่าแก้ pain อะไร
เจอใน: Landing, บทเรียน 8 (Step 8.4)
