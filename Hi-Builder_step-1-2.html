STEP 1.2 / 1.7 15 นาที

โลก Tech มีอะไรบ้าง

จบ Step นี้คุณจะ

  • เข้าใจว่า "โลก tech" มีองค์ประกอบหลักอะไรบ้าง
  • รู้ว่าใน Hi, Builder เราจะทำส่วนไหน (และไม่ทำส่วนไหน)
  • ไม่กลัวคำศัพท์เทค พอเจอแล้วเดาบริบทได้

🍳 เริ่มที่เรื่องที่ทุกคนรู้กันก่อน — ร้านอาหารตามสั่ง

อาจารย์อยากให้พวกเราลืมเรื่อง tech ไปสักครู่ — มาคิดถึง ร้านอาหารตามสั่ง ที่อยู่ใกล้บ้านแทน

ที่ร้านนั้น คุณเดินเข้าไป มอง เมนู บนผนัง สั่ง "ผัดกะเพราหมูสับ ใส่ไข่ดาว" กับ พนักงานหน้าเคาน์เตอร์ เธอตะโกนเข้าครัว แม่ครัว ใช้สูตรของร้าน หยิบวัตถุดิบจากตู้เย็น ทำเสร็จส่งกลับมาให้คุณ

ใน 30 วินาทีนี้ พวกเราเพิ่งเข้าใจโลก tech ทั้งใบไปแล้ว — แค่ไม่รู้ตัว

🗺️ แผนที่โลก Tech = ร้านอาหารตามสั่ง

ในร้านอาหาร ในโลก Tech อธิบายสั้นๆ
เมนู + หน้าเคาน์เตอร์ Frontend สิ่งที่ผู้ใช้เห็น/กด เช่น หน้าเว็บ ปุ่ม รูปภาพ
ครัว (ที่ปรุงอาหาร) Backend ส่วนทำงานหลังบ้าน คำนวณ ประมวลผล
ตู้เย็น + ชั้นเก็บของ Database ที่เก็บข้อมูลทั้งหมด
ที่อยู่ของร้าน Hosting คอมที่เก็บเว็บไว้ให้คนเข้าถึงได้
ป้ายชื่อร้าน Domain (URL) เช่น ajarnkwan.github.io
คนกินที่เดินเข้าร้าน Browser Chrome / Safari ที่ใช้เปิดเว็บ
สูตรอาหาร Code คำสั่งที่บอกคอมว่าจะทำอะไร
แม่ครัว Developer คนเขียน code
ผู้ช่วยในครัว ✨ AI ตัวช่วยที่ทำงานได้หลายอย่าง

🏪 แล้วใน Hi, Builder เราจะเป็นอะไร?

นี่คือคำถามที่ดีที่สุด — เพราะคำตอบจะทำให้พวกเราเลิกกลัวคำศัพท์เทคที่เห็นในข่าว

ใน Hi, Builder พวกเราจะทำหน้าที่ เปิดร้านของตัวเอง — แต่ไม่ใช่ร้านใหญ่ที่มีทุกอย่าง

Hi, Builder = "ร้านขายขนมหน้าบ้าน"

ไม่มีครัวใหญ่ ไม่มีตู้เย็นเก็บของเป็นพันรายการ ไม่ต้องจ้างแม่ครัว
มีแค่ — ขนมที่อร่อย + ป้ายชื่อ + ที่ตั้งให้คนเดินผ่าน

แปลเป็นภาษา tech:

ส่วนของโลก Tech ใน Hi, Builder หมายเหตุ
✅ Frontend ทำเอง เว็บที่ผู้ใช้เห็น
✅ Hosting GitHub Pages ฟรี ของ Microsoft
✅ Domain URL จาก GitHub เช่น username.github.io
✅ Code ใช้ AI ช่วย ไม่ต้องเขียนเองตั้งแต่ต้น
❌ Backend ไม่ทำ เว็บทำงานในเครื่องผู้ใช้
❌ Database ไม่ทำ ใช้ localStorage แทน (บทเรียน 6)
❌ AI ขั้นสูง ไม่ทำ ใช้ AI ที่มีอยู่แล้ว ไม่สร้างเอง

ที่บอก "❌" ไม่ใช่เพราะมันยาก — แต่เพราะ คอร์สนี้พิสูจน์ก่อนว่า "เริ่มได้" สิ่งที่ ❌ พวกเราเรียนต่อในอนาคตได้

🎤 จุดสำคัญที่ต้องจำ

  1. ไม่ต้องรู้ทุกอย่างก่อนเริ่ม นักเรียน Hi, Builder ที่จบไปจะเข้าใจ tech ทั้งใบมั้ย? ไม่ — แต่จะเข้าใจ "ส่วนของตัวเอง" ดีพอที่จะสร้างของได้
  2. AI = ผู้ช่วยในครัว ไม่ใช่แม่ครัวแทนเรา AI ทำงานเร็ว แต่ตัดสินใจให้เราไม่ได้ — เรายังต้อง "สั่ง" และ "ตรวจ" (เรื่องตรวจอยู่ใน บทเรียน 4)
  3. คำศัพท์เทคที่ดูยาก = ส่วนหนึ่งของร้าน ครั้งหน้าได้ยินคำว่า "API" "Server" "Cloud" — ลองนึกว่ามันคือ "ส่วนไหนของร้าน" ส่วนใหญ่จะเดาถูก
