STEP 1.4 / 1.7 15 นาที

สมัคร GitHub

จบ Step นี้คุณจะ

  • เข้าใจว่า GitHub คืออะไร — และทำไม Builder ต้องมี
  • มีบัญชี GitHub ของตัวเอง
  • พร้อมใช้สร้าง URL แรกใน Step 1.7

🤔 GitHub คืออะไร?

GitHub = บริษัท เก็บไฟล์ code ของ Microsoft ใหญ่ที่สุดในโลก — แต่ไม่ใช่แค่ที่เก็บ ยังเป็น "หน้าร้าน" ให้ Builder ทุกคนได้ด้วย

📦

ที่เก็บโค้ด (Cloud)

เก็บไฟล์เว็บของเราไว้ ไม่หาย ไม่ลืม — เปิดจากเครื่องไหนก็ได้

🌐

ที่ตั้งเว็บฟรี

มี GitHub Pages — เว็บของเรามี URL เปิดได้จริง คนอื่นเข้าถึงได้ทันที

📛

นามบัตรของ Builder

โปรไฟล์ GitHub = Portfolio — ใช้สมัครงานได้ ใส่ใน CV ได้

🤝

ชุมชนของผู้สร้าง

ของฟรีเยอะมาก เห็นงานคนอื่น เรียนรู้ได้ตลอด

เปรียบเทียบ: ถ้าโลก tech คือ ร้านอาหาร (จาก Step 1.2) — GitHub คือ ที่ดิน + ที่อยู่ของร้าน

ฟรี ไม่ต้องเสียค่าเช่า — และเปิด 24 ชั่วโมง

สำคัญ: ใน Hi, Builder เราจะใช้ GitHub แค่ ส่วนพื้นฐาน — ไม่ต้องเรียน Git command line ตอนนี้ แค่สมัคร + อัพไฟล์ผ่านหน้าเว็บก็พอ

🚀 สมัคร GitHub แบบ step-by-step

มี 5 ขั้นตอน ใช้เวลา ~10 นาที — เปิดหน้านี้คู่กับเว็บ GitHub แล้วทำตามได้เลย

1
เข้าเว็บ github.com

เปิด browser (Chrome / Safari / Edge) แล้วพิมพ์ github.com ในช่อง URL

คุณจะเห็นหน้าแรกของ GitHub มีปุ่ม "Sign up" มุมบนขวา — กดที่ปุ่มนั้น

tip ถ้าเห็นข้อความเป็นภาษาอังกฤษทั้งหมด ไม่ต้องตกใจ — Browser มีฟีเจอร์ "แปลหน้าเว็บ" คลิกขวา → "Translate to Thai" ช่วยได้
github.com
⚫ GitHub
Build the world's best software
Sign up →
2
กรอก Email

GitHub จะถาม email ก่อนเป็นอย่างแรก — ใช้ email ที่เปิดอยู่ตลอด เพราะต้อง verify

ใช้ email อะไรดี?

  • Gmail / Hotmail / Outlook ส่วนตัว ใช้ได้ทุกตัว
  • ไม่แนะนำ email ของบริษัท/ที่ทำงาน — ออกจากงานแล้วอาจเข้าไม่ได้

กรอก email แล้วกด "Continue"

ระวัง 1 email = 1 บัญชี GitHub ถ้าเคยสมัครแล้ว ต้อง "Sign in" แทน — ไม่ใช่สมัครใหม่
github.com/signup

Welcome to GitHub!

Enter your email
[email protected]
Continue →
3
ตั้ง Password + Username

หน้าถัดไปจะให้ตั้ง Password (รหัสผ่าน) — อย่างน้อย 8 ตัวอักษร มีตัวเลข + ตัวอักษร

จากนั้นจะให้ตั้ง Username — ชื่อนี้สำคัญมาก เพราะจะกลายเป็น URL ของคุณ:

  • เช่น username = mybuilder → URL = mybuilder.github.io
  • ใช้ตัวอักษรอังกฤษ a-z, ตัวเลข 0-9, และ - (ขีด)
  • ห้ามมีช่องว่าง ห้ามมีตัวอักษรไทย
คิดให้ดี Username เปลี่ยนได้ในอนาคต แต่ถ้ามีคนตามคุณเยอะแล้ว เปลี่ยนทีหลังจะวุ่นวาย — ลองตั้งให้ เกี่ยวกับงานคุณ หรือ ชื่อจริง
github.com/signup

••••••••••
Enter a username
mybuilder

4
ยืนยัน Email (Verify)

GitHub จะส่ง email ยืนยัน ไปที่ email ที่กรอกไว้ — เปิด email แล้วกดปุ่ม "Verify email address" ในเมล

ถ้าไม่เห็นเมล ลอง:

  • เช็คใน Junk / Spam
  • รอ 1-2 นาที email อาจมาช้า
  • กด "Resend email" ใน GitHub
สำคัญ ห้ามข้ามขั้นนี้! ถ้าไม่ verify จะใช้บางฟีเจอร์ไม่ได้ (รวมถึง GitHub Pages ที่จะใช้ใน Step 1.7)
From: [email protected]
To: [email protected]
[GitHub] Please verify your email
Hi mybuilder,

Click the button below to verify your email address.

Verify email address
5
ยินดีด้วย! คุณมีบัญชีแล้ว

เมื่อ verify แล้ว คุณจะกลับเข้า GitHub ได้ — ระบบจะถามคำถามไม่กี่ข้อ (ใช้ทำอะไร / เคยเขียนโค้ดมั้ย) ตอบตามจริง หรือกด "Skip" ก็ได้

หลังจากนั้น คุณจะเห็น Dashboard หน้าหลักของ GitHub — มีโปรไฟล์ของคุณพร้อมใช้งาน

ลองเข้า URL github.com/yourusername (แทน yourusername ด้วย username ที่ตั้ง) — นี่คือหน้าโปรไฟล์ของคุณ ทุกคนเข้าดูได้

จำ url นี้ Bookmark github.com ไว้ใน browser — Step ต่อๆ ไปจะกลับมาที่นี่บ่อย
github.com/mybuilder

เช็คตัวเองก่อนไป Step ถัดไป

ติ๊กในใจว่าทำครบทุกข้อหรือยัง

  • มี email + password ของบัญชี GitHub
  • ตั้ง username แล้ว (จำได้ว่าใช้ตัวอะไร)
  • กด verify email ในเมลแล้ว
  • เข้า github.com/yourusername แล้วเห็นโปรไฟล์
