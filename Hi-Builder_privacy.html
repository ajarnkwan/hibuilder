อัพเดต: พฤษภาคม 2026

สั้น ๆ: Hi, Builder ฟรี — เก็บข้อมูลของพวกเราในเบราว์เซอร์ของพวกเราเอง ไม่ส่งกลับมาที่อาจารย์ ไม่ขายข้อมูล ไม่มีโฆษณา

1. ข้อมูลที่ Hi, Builder เก็บ

1.1 ข้อมูลใน localStorage (เครื่องของพวกเรา)

กิจกรรมในคอร์สนี้บันทึกข้อมูลใน localStorage ของเบราว์เซอร์ — เก็บอยู่ในเครื่องของพวกเรา ไม่ได้ส่งกลับไปที่ server:

  • Step 1.5 — Asset Mind Map: ความรู้ ทักษะ Network ประสบการณ์ ที่พวกเรากรอก
  • Step 1.5 — Reflection: ข้อความที่พวกเราเขียนตอบคำถาม
  • Step 1.7 — URL ของพวกเรา: ลิงก์เว็บที่พวกเราใส่
หมายเหตุ ข้อมูลนี้อยู่ในเครื่องของพวกเราเท่านั้น — ถ้าใช้คนละเครื่อง / clear browser cache → ของจะหาย แนะนำให้ดาวน์โหลด JSON เก็บไว้ใน Step 1.5

1.2 ข้อมูลที่ ไม่เก็บ

  • ไม่มี cookie ติดตาม (no tracking cookies)
  • ไม่ใช้ analytics ที่ติดตามพฤติกรรมส่วนบุคคล
  • ไม่เก็บ email, ชื่อ, หรือข้อมูลส่วนตัว
  • ไม่ส่งข้อมูลไปยัง third-party

1.3 GitHub & Discord

ใน Step 1.4 พวกเราจะสมัคร GitHub และเข้าร่วม Discord — ทั้ง 2 บริการมี privacy policy ของตัวเอง:

  • GitHub Privacy Statement
  • Discord Privacy Policy

Hi, Builder ไม่เห็นข้อมูลของพวกเราใน 2 บริการนี้

2. การลบข้อมูล

เนื่องจากข้อมูลทั้งหมดอยู่ในเครื่องของพวกเรา — การลบทำได้ด้วยตัวเอง:

  • Chrome: Settings → Privacy → Clear browsing data → Cookies and other site data
  • Safari: Settings → Privacy → Manage Website Data → Remove
  • Firefox: Settings → Privacy & Security → Clear Data

3. ข้อกำหนดการใช้งาน

3.1 ฟรีและเปิด

Hi, Builder เป็นคอร์สฟรีเพื่อการศึกษา — ใช้ส่วนตัวได้ ไม่จำกัด

  • เรียนเองได้
  • แชร์ลิงก์ให้คนอื่นได้
  • ใช้สอนในห้องเรียนได้ (ติดต่ออาจารย์ก่อน)

3.2 ลิขสิทธิ์เนื้อหา

เนื้อหาในคอร์ส (text, code, mockup, ภาพประกอบ) เป็นลิขสิทธิ์ของ ผศ.ดร.ขวัญ เพชรสว่าง — ห้ามคัดลอกไปสร้างคอร์สอื่นเพื่อขาย

3.3 ของที่พวกเราสร้าง

เว็บ HTML และของอื่นๆ ที่พวกเราสร้างในคอร์สนี้ เป็นของพวกเราเอง — ใช้/ขาย/แชร์ได้ตามใจ

4. ข้อจำกัดความรับผิด

Hi, Builder เป็นคอร์สสอน — ไม่ใช่บริการจัดเก็บข้อมูล:

  • ของในเบราว์เซอร์อาจหายเองตามนโยบายของ browser
  • GitHub / Discord มีการเปลี่ยน feature/UI ตลอดเวลา — เนื้อหาอาจคลาดเคลื่อนเล็กน้อย
  • AI tools (Claude, ChatGPT, ฯลฯ) เปลี่ยนแปลงตลอด — quota, ราคา, ฟีเจอร์ อาจไม่ตรงกับที่บอกในคอร์ส

อาจารย์พยายามอัพเดตเนื้อหาให้ใหม่ที่สุด แต่ไม่รับประกันความถูกต้องสมบูรณ์ 100%
