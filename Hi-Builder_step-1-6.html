STEP 1.6 / 1.7 20 นาที

โครงสร้างของเว็บ

จบ Step นี้คุณจะ

  • เข้าใจว่าเว็บประกอบด้วย 3 ส่วน — HTML / CSS / JS
  • อ่านโครง HTML สั้นๆ ได้ — รู้ว่าตรงไหนคือหัวข้อ ตรงไหนคือเนื้อหา
  • เห็นภาพว่าแก้สีไหน เปลี่ยนข้อความตรงไหนของ code

🏗️ เว็บประกอบด้วยอะไรบ้าง?

ก่อนใช้ AI สร้างเว็บใน Step ถัดไป — พวกเราต้องรู้ก่อนว่า "เว็บ" จริง ๆ ประกอบด้วยอะไร เพื่อที่ เวลาขอ AI จะรู้ว่ากำลังขออะไร

เว็บทุกหน้า — จาก Facebook ถึง Google ถึงเว็บที่พวกเรากำลังเปิดอยู่ — ล้วนสร้างจาก 3 ภาษา ที่ทำงานคนละหน้าที่:

🦴
HTML

โครงกระดูก

บอกว่ามีอะไรอยู่ตรงไหน — หัวข้อ ย่อหน้า รูป ปุ่ม

🎨
CSS

เสื้อผ้า

บอกว่าหน้าตาเป็นไง — สี ฟอนต์ ระยะห่าง ขนาด

⚡
JS

การเคลื่อนไหว

บอกว่ากดปุ่มแล้วเกิดอะไร — เปลี่ยนหน้า บันทึก คำนวณ

ย้อนไป Step 1.2 — เปรียบเทียบกับร้านอาหาร:

HTML = เมนูที่บอกว่าร้านมีอะไร
CSS = การตกแต่งร้าน สี ป้าย
JS = คำสั่งที่ลูกค้ากด → แม่ครัวทำตาม

ใน Hi, Builder บทเรียน 1 พวกเราจะใช้ HTML เป็นหลัก — เพราะเริ่มต้นได้ง่ายสุด CSS กับ JS จะเรียนต่อในบทถัดๆ ไป

🔬 ผ่า HTML สั้นๆ ดู

ดู HTML 10 บรรทัดนี้ — โครงเว็บที่ง่ายที่สุดในโลก

โครงพื้นฐานของหน้าเว็บ
<!DOCTYPE html> <html> <head> <title>เว็บของฉัน</title> </head> <body> <h1>สวัสดี</h1> <p>นี่คือเว็บแรกของฉัน</p> </body> </html>
<!DOCTYPE html> บอกเบราว์เซอร์ "นี่คือ HTML นะ"
<head> ข้อมูลเบื้องหลัง (ชื่อหน้า, font)
<body> ของที่คนจะ "เห็น"
<h1> หัวข้อใหญ่
<p> ย่อหน้า ข้อความ

ของพวกนี้ในวงเล็บมุม < > เรียกว่า "tag" — เป็นเหมือน "ป้ายชื่อ" บอกเบราว์เซอร์ว่า ส่วนนี้คืออะไร: <h1> = หัวข้อ, <p> = ย่อหน้า, <body> = เนื้อหาหลัก

สังเกตว่า tag ทุกตัว มีคู่ — เปิด <p> ต้องปิด </p> (มีขีดทับ / นำหน้า) — เหมือนวงเล็บที่ต้องปิด

เห็นภาพแล้วใช่ไหม? — เว็บไม่ใช่อะไรลึกลับ มันคือ text ในโครงที่กำหนดไว้ เปลี่ยน text → เว็บเปลี่ยน

ใน Step 1.7 ถัดไป พวกเราจะ ไม่ต้องเขียน HTML เองทีละบรรทัด — เราจะให้ AI สร้างให้ แต่พอเข้าใจโครงแล้ว เวลา AI ส่งมา พวกเราจะอ่านได้ว่ามีอะไรอยู่ตรงไหน + แก้ได้เอง

เช็คตัวเองก่อนไป Step 1.7

ติ๊กในใจว่าเข้าใจหรือยัง

  • อ่าน HTML 10 บรรทัดแล้วบอกได้ว่าตรงไหนคือหัวข้อ ตรงไหนคือย่อหน้า
