STEP 1.7 / 1.7 30 นาที ⭐ peak ของบทเรียน

สร้าง URL แรก

จบ Step นี้คุณจะ

  • มี URL ของตัวเอง username.github.io ที่เปิดได้จริง
  • สร้างเว็บโปรไฟล์แรกด้วย AI (ใช้ asset map จาก Step 1.5)
  • เห็นเว็บของตัวเองทำงานบนอินเทอร์เน็ตจริง — ครั้งแรกของชีวิต Builder

นี่คือ Step ที่ เปลี่ยนพวกเราจาก "ผู้เรียน" → "ผู้สร้าง" — เพราะจบ Step นี้ พวกเราจะมีของจริง URL จริง ที่เปิดบนมือถือเพื่อนได้ทันที

เว็บแรกไม่ต้องสวย ไม่ต้องสมบูรณ์ — แค่ "เปิดได้" ก็ชนะแล้ว

เพราะของจริง > ของในใจ

🤖 Phase 1 — ให้ AI สร้าง HTML

เราจะใช้ AI (Claude หรือ ChatGPT — ตัวที่อาจารย์เคยพูดถึงใน Step 1.3) สร้างหน้าเว็บโปรไฟล์ของพวกเรา โดยใช้ asset map ที่กรอกใน Step 1.5

1
เปิด Claude หรือ ChatGPT

เปิดอันใดอันหนึ่งใน browser:

  • claude.ai
  • chat.openai.com

เริ่มแชทใหม่ (กด "New chat")

2
copy prompt นี้ไปใช้

นี่คือ prompt ที่อาจารย์เตรียมไว้ — กดปุ่ม Copy แล้ววางใน chat ของ AI:

📋 PROMPT
ช่วยสร้างหน้าเว็บ HTML ไฟล์เดียว เป็นหน้า "About me" ของฉัน ข้อกำหนด: - เป็น HTML, CSS, JS ในไฟล์เดียว ไม่ต้องใช้ external library - โทนสีอบอุ่น ใช้ฟอนต์อ่านง่าย mobile-friendly - มี 5 sections ตามนี้: 1. ชื่อของฉัน + 1 ประโยคแนะนำตัว 2. ความรู้ที่ฉันมี (list 3-5 ข้อ) 3. ทักษะที่ฉันถนัด (list 3-5 ข้อ) 4. Network ของฉัน (list 3-5 ข้อ) 5. ประสบการณ์สำคัญ (list 3-5 ข้อ) - มี footer เล็กๆ ว่า "สร้างด้วย Hi, Builder by อาจารย์ขวัญ" ฉันจะใส่ข้อมูลจริงเองหลังได้ HTML แล้ว — ตอนนี้ใส่ placeholder ก็ได้
ทำไมถึงไม่ใส่ข้อมูลจริงตั้งแต่แรก? เพราะถ้าใส่ไปครั้งเดียวยาว ๆ AI อาจตีความผิด — ดีกว่า ขอ skeleton ก่อน แล้วค่อยใส่ข้อมูลจริงทีหลัง
3
รอ AI สร้างให้ + copy code

AI จะตอบมาเป็น HTML code 1 ก้อน — copy ทั้งก้อน (กดปุ่ม "Copy code" ใน AI หรือ select ทั้งหมด)

claude.ai
ช่วยสร้างหน้าเว็บ HTML ไฟล์เดียว...
นี่คือ HTML สำหรับหน้า About me ของคุณ:

<!DOCTYPE html>
<html lang="th">
...
ก่อนไปต่อ เก็บ code ไว้ — เปิด Notepad / TextEdit / Google Docs แล้ววางไว้ก่อน เผื่อต้องใช้
4
แก้ placeholder เป็นข้อมูลจริง

เปิด Asset Map ที่ทำใน Step 1.5 (ในหน้านี้, อาจกดเปิด Step 1.5 ใน tab ใหม่เพื่อดู)

กลับไปบอก AI ต่อในแชทเดิม:

📋 PROMPT 2
ดีมาก ทีนี้ใส่ข้อมูลจริงของฉัน: ชื่อ: [ใส่ชื่อจริงของคุณ] แนะนำตัว: [1 ประโยคสั้น ๆ เช่น "อาจารย์เศรษฐศาสตร์ที่อยากเรียนรู้สิ่งใหม่"] ความรู้: - [ข้อ 1 จาก asset map] - [ข้อ 2] - [ข้อ 3] ทักษะ: - [ข้อ 1] - [ข้อ 2] - [ข้อ 3] Network: - [ข้อ 1] - [ข้อ 2] - [ข้อ 3] ประสบการณ์: - [ข้อ 1] - [ข้อ 2] - [ข้อ 3] ส่ง HTML version ใหม่ที่ใส่ข้อมูลจริงเรียบร้อย

AI จะส่ง HTML ใหม่ที่ใส่ข้อมูลจริงให้ — copy version นี้ไปใช้

📦 Phase 2 — สร้าง repo บน GitHub

ตอนนี้เรามี HTML แล้ว ต้องเอาไป "ปล่อยขึ้นเว็บ" ผ่าน GitHub Pages

คำใหม่ใน Phase นี้ Repo (Repository) = "โฟลเดอร์โปรเจกต์" บน GitHub — เก็บไฟล์ทุกไฟล์ของเว็บเดียวไว้ด้วยกัน 1 เว็บ = 1 repo Commit = บันทึก/save การเปลี่ยนแปลงเข้า repo — มี history ดูย้อนได้ Deploy = ปล่อยเว็บออกสู่อินเทอร์เน็ต — หลัง commit GitHub จะ deploy อัตโนมัติ
5
เข้า GitHub แล้วสร้าง repo ใหม่

ไปที่ github.com → กดปุ่ม "New repository" มุมบนขวา (เครื่องหมาย +)

  • Repository name: username.github.io (แทน username ด้วย username ของพวกเราจริง)
  • เลือก Public
  • ติ๊ก "Add a README file"
  • กด "Create repository"
github.com/new

mybuilder.github.io
✓ This will be your User Pages site

Create repository →
สำคัญที่สุด ชื่อ repo ต้องเป็น username.github.io (ตรงเป๊ะกับ username) — ถ้าตั้งชื่ออื่น GitHub Pages จะไม่ทำงานเป็น user site
6
สร้างไฟล์ index.html

หลังสร้าง repo เสร็จ — กดปุ่ม "Add file" → "Create new file"

  • ตั้งชื่อไฟล์: index.html
  • วาง HTML code ที่ AI สร้างให้ ลงในกล่องใหญ่
  • เลื่อนลงล่างสุด → กด "Commit changes"
github.com/.../new

นึกถึง commit ว่า... Commit = กด save ที่บันทึกประวัติได้ — เปลี่ยนใจค่อยกลับมาแก้ทีหลัง หรือดู version เก่าได้

🌐 Phase 3 — เปิดดู URL จริง

7
รอ GitHub Pages deploy (~1-2 นาที)

หลัง commit แล้ว GitHub จะ deploy เว็บอัตโนมัติ ใช้เวลา 1-2 นาที — ระหว่างนี้นั่งรอได้

ถ้าอยากเช็คว่าเสร็จหรือยัง: ไปที่ Settings → Pages ใน repo จะเห็นข้อความ "Your site is live at..." เมื่อพร้อม

8
เปิด URL ของตัวเอง

เปิด tab ใหม่ในเบราว์เซอร์ → พิมพ์ URL:

username.github.io

(แทน username ด้วยของพวกเราจริง)

คุณจะเห็น เว็บโปรไฟล์ของตัวเอง เปิดบนอินเทอร์เน็ตจริง — โชว์ใครก็ได้ ใช้ได้บนมือถือด้วย

mybuilder.github.io
